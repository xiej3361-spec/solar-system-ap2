## 2. 对实现的直接约束（已落到代码）

1. **不允许分层同色圆环**：日冕用单个 billboard + 连续衰减 + 噪声丝状结构（`index.html` 的 `uCorona` 分支）。
2. **拖拽必须固定符号**：偏航/俯仰轨道模型，pitch 夹紧 ±1.48 rad（`js/camera.js`）。
3. **克制的地表/标签对比**：标签与轨道使用低饱和色，聚焦时才用强调色。
4. **时间一致性**：一个 `sim.date` 派生所有角度（`js/scene.js` + `js/astro.js`）。
