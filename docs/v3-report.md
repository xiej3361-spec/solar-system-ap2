## 2. 关键问题的根因与修复

### 2.1「三圈光晕很突兀」

- **根因**：旧实现用 2 个加色混合的球壳（scale 1.5 / 2.0）+ 常量 tint，`rim = 1-|dot(N,V)|` 在每个壳上都是一条硬边；两层壳叠加后在屏幕上形成两条可辨识的亮环，且没有方向性/噪声结构。
- **修复**：删除球壳方案，改为**单个面向相机的 quad**（`billboardModel`）：径向连续衰减 `exp(-(2.9r)^1.55)` × 角度向 fBm 丝状结构 × 边缘软掩码，并结合日面掩码（`uCoronaDisk`）让日冕从日面外缘淡入。日面本体增加 3D 值噪声颗粒与临边因子。
- **验证**：太阳特写径向亮度剖面（步长 16px，采样 8°/次）：`[130,236,242,242,241,240,240,236,240,236,126,157,183,181,171,162,148,116,94,78,73,67,66,64,54,48,47]` —— 外圈严格单调衰减（脚本断言 `all(delta >= -4)` 为 True），不再出现「暗环 + 亮环」。

### 2.2 鼠标拖拽方向不稳定

- **根因**：旧实现是 Shoemake 虚拟轨迹球：屏幕点投到半球（`d²≤½` 与 `>½` 两个分支切换投影面），两次拖拽的旋转轴由叉积给出并累积成四元数/矩阵；当拖拽跨越投影边界或接近极点时，累积旋转的「上方向」跟着翻转，同一方向拖拽在屏幕不同位置会得到相反的垂直变化。
- **修复**：整机替换为**偏航/俯仰球面轨道**：`eye = target + dist·(sin yaw cos pitch, sin pitch, cos yaw cos pitch)`，`up` 恒为世界 Y，pitch 夹紧 ±85°；拖拽符号固定（右拖 `yaw -= dx·1.05`，下拖 `pitch += dyDown·1.05`），永不翻转、无滚转。
- **验证**：真实鼠标事件（`Input.dispatchMouseEvent` 分 8 步拖拽）——
  - 向下拖 240px：pitch `0.291 → 1.249`（单调增大，未越界）
  - 连续两次向右拖 200px：yaw `0.817 → 0.342`（同向单调）
  - 相机自测 37/37 PASS（含 20 次同向拖拽符号一致、上限夹紧、focus 拖拽环绕、eclipse 拖拽不恢复自动运动、WASD 对角不加速）

### 2.3 日食/月食演示不直观

- **根因**：
  1. 旧实现只冻结了仿真时间，**相机位姿每帧仍被 `updateEclipseView` 覆盖**，太阳表面也没有动画时间概念；
  2. 没有真实的阴影几何：`uShadow` 只是一个按对齐角度的亮度系数，画面里没有本影/半影范围；
  3. 旧「地面视角」其实是把相机放在月球附近让角尺寸凑成 88%，不是从地球表面看；
  4. 进入后再点另一个演示不会重新取景，退出也没有状态恢复。
- **修复**：
  1. **全量冻结**：`frozen = DEMO.freeze || simPaused || eclipse`，时间、太阳动画时间（`uTime`）、漫游全部停止；相机只允许用户主动操作；
  2. **解析阴影**：由太阳/月球/地球半径解析求月球本影锥（`Lu = d_sm·R_m/(R_s-R_m)`）、半影锥、地影锥（`Le = d_se·R_e/(R_s-R_e)`），得到地球表面阴影斑位置与半径；
  3. **可视化**：半影锥 5%、本影锥 9% 加色体积；地表阴影用 **乘色混合**（`DST_COLOR/ZERO`）真正压暗（本影 0.06、半影渐变到 0.92）；月食时同样用轴线阴影把月面压暗；
  4. **地面视角**：相机放到地球向阳面地表点（日食）或背日面点（月食）朝目标观测；同时右下/左下方小窗用 `groundview.js` 按**真实角尺寸**绘制日面/月面遮挡形态；
  5. **状态保存/恢复**：进入时保存 `mode/date/time/rate/paused/projection/eye/at`，`Esc` 或「返回太阳系」恢复。
- **验证**：日食模式 `sim.time` 与地月位置两次读取完全一致（冻结成立）；`earthSpot.umbraR = 0.0343 > 0`（本影真正落在地表）；地面观测月球/太阳角半径比 1.23（可形成全食/近全食）；退出后 `cam.mode=focus, sim.mode=real`。

### 2.4 时间/自转/光照/表面不一致

- **根因**：旧实现只有一个按帧累加的「仿真年」，行星角度由 `年/周期` 推算；地球自转相位与太阳方向无关（贴图旋转与光照脱节）；倾角在轨道节点内施加（地轴随公转摆动，无法产生真实季节）。
- **修复**：
  - 新增 `sim.date`（UTC Date）作为**唯一时间源**，`astro.js` 由它派生行星日心黄经、地球自转相位、太阳直射点、晨昏线交点；
  - 地球自转相位 = 直射点经度 − 180°（直射点经线朝向太阳）；
  - 地轴倾角用共轭矩阵 `R_y(−rev)·R_z(ε)·R_y(rev)` 施加在局部，使地轴方向**不随公转摆动**（产生真实季节与倾角照明）；
  - 真实模式下自转按恒星周期从模拟时刻直接计算，不逐帧累加；
  - 轨道线开关只控制绘制，不参与计算（位置始终由同一时间源推导）。

## 3. 真实天文模式 vs 自定义演示模式

| | 真实天文模式（默认） | 自定义演示模式 |
|---|---|---|
| 时间 | `sim.date`（UTC，可输入任意时刻），倍率 `10^slider`（1×…100000×） | `sim.time`（仿真年），公转/自转倍率独立可调 |
| 行星位置 | JPL 近似轨道要素 → 日心黄经；日心距按真实/平均比值缩放展示半径 | 周期比例的公转角度 |
| 地球自转 | 由太阳直射点经度决定 | 由自转倍率累加 |
| 地轴倾角 | 固定 23.44°，绕固定世界轴（季节成立） | 滑条可调，绕局部 Z 轴（展示用） |
| 面板信息 | 直射点纬度/经度、晨昏线–赤道交点、当地太阳时、UTC 时刻 | 明确提示「为展示参数，不代表真实天文状态」 |
| 滑条 | 公转/自转/倾角滑条禁用（避免混用） | 全部可用 |

## 4. 数据源调查（太阳活动层，本轮未接入）

已核查候选源（公开、无需密钥）：

- `https://services.swpc.noaa.gov/json/solar_regions.json`（NOAA SWPC，太阳活动区：经纬度、面积、磁类型）
- `https://services.swpc.noaa.gov/json/sunspot_report.json`（黑子群报告）
- NASA/CCMC DONKI（CME/耀斑事件列表，需按事件查询）

**判断**：SWPC 的 `solar_regions.json` 含 `latitude/longitude/area`，可映射到日面坐标；但静态部署站点直接 `fetch` 需要确认其 CORS 允许与字段稳定性，且本轮时间预算已用于 P0/P1 的几何与渲染改造。因此**未接入**，也未用任何随机/伪造数据冒充观测。界面中不显示任何「太阳活动」数字。
后续接入建议：`fetch` 失败时显示「上次成功更新 / 不可用」，并把数据来源与时间戳写在面板上；无坐标的 CME 只做事件列表。

## 7. 限制与未完成项

1. **星历精度**：行星位置为 JPL「Approximate Positions」近似（1800–2050），未含岁差/章动/光行差；月球为平均要素模型（距离取平均），误差可达数度。面板已标注「简化近似，非精确星历」。
2. **尺度**：太阳系仍为教学夸张尺度；月球半径/轨道经调整，使从地表观测的日月视直径接近真实（否则无法演示食相）。这是教学取舍，已在 config 与 README 注明。
3. **太阳活动数据**：仅完成数据源调查，未接入（见 §4）。
4. **地图投影**：未做平面地图上的直射点/晨昏线绘制，仅提供数值信息与三维晨昏线；要求中的「在地图上显示」为部分完成。
5. **REA**：会话内没有可调用的 REA MCP 工具，参考站调查用无头浏览器直采（见 `docs/evidence-v3.md`）。
6. **截图人工复核**：本模型无法直接查看图片，视觉结论基于像素统计（亮度剖面、差异像素、区域均值）与页面状态断言；建议人工过一遍 9 张验收截图。
